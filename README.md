# Abhaya – Women Safety Android Application

Abhaya is an Android-based women safety application designed to provide quick access to emergency assistance. The app allows users to manage emergency contacts, access helpline numbers, and share live location details during emergencies.

---

## Features

- User Authentication (Login & Signup)
- Home Dashboard with SOS Button
- Emergency Contacts Management
- Emergency Call & SMS Alert
- Live Location Tracking
- Nearby Emergency Services (Police, Hospitals)
- Self Defense Videos
- Privacy Policy

---

## Tech Stack

- **Platform:** Android  
- **Language:** Java  
- **IDE:** Android Studio  
- **Build Tool:** Gradle  
- **APIs:** Google Maps API, Location Services

1. Clone the repository
   ```bash

   ```
2. Open in Android Studio  
3. Add Google Maps API key  
4. Build & Run on emulator or device
